## Cómo está organizado este libro

Siete bloques. Cada uno responde a una pregunta operativa concreta:

| Bloque | Pregunta que responde |
|---|---|
| **01 · Quiénes somos** | ¿Quién hace qué en eXcalando? |
| **02 · Modelo de negocio** | ¿Cómo ganamos plata y cuánto cuesta operar? |
| **03 · Producto** | ¿Qué vendemos exactamente y cómo se construye? |
| **04 · Stack técnico** | ¿En qué corre todo y qué hacer si se rompe? |
| **05 · Go-to-Market** | ¿Cómo conseguimos clientes? |
| **06 · Operación** | ¿Cómo entregamos y cobramos? |
| **07 · Roadmap** | ¿Qué viene y qué está pendiente? |

## Acceso por rol

Este libro **NO es público**. Cada rol ve sólo lo que le corresponde — ver [`Socios y roles`](/interno/socios-y-roles/).

| Rol | Acceso |
|---|---|
| Socios fundadores (Javier · Harol) | Todo |
| Contador / aliado fiscal | Sólo `06 · Operación / Contabilidad` |
| Freelancer ad-hoc | Sólo el runbook del proyecto puntual |
| Comercial referido | Sólo `05 · Go-to-Market / Referidos` |
| Cliente | Nada de este libro. Tiene su propio sitio. |

> El **manifiesto público**, el **lema de marca** y la **promesa al cliente** viven en [excalando.com](https://excalando.com). Acá NO los duplicamos.
