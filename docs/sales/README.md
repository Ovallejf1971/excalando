## Convenciones de copy

Todos los materiales siguen el ADN definido en `.agents/product-marketing-context.md`:

- **Tratamiento:** tú estricto (nunca vos, nunca usted)
- **Tono:** directo, irreverente contra "lo viejo del sector", cálido con el cliente
- **Arquetipo:** Rebelde Liberador
- **Jamás:** "sinergia", "transformación 360°", "ecosistema", "partner estratégico", jerga inflada
- **Estructura de marca:** `eXcalando · Agencia Digital` (estilizada con X mayúscula en branding visual; `excalando` minúsculas en URLs/código)

## ⚠️ Importante para uso

- **Contrato:** este template es **borrador comercial**, no documento legal. Antes de firmar con cliente real, **revisión obligatoria por abogado**.
- **Precios:** vienen del `kb-content.json` (fuente única de verdad). Si cambian precios, actualizar primero allí y propagar a estos docs.
- **Logos y diseño:** el contenido es definitivo; los visuales esperan al rediseño de logo SVG (pendiente del frente branding).
